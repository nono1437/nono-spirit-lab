# nono Spirit Lab

一个以手机横屏为第一体验目标的原创精灵回合制战斗实验场。

## v0.2.0

- 真正的一屏横屏战斗布局，不再纵向滚动
- 共用竞技场舞台，双方血条固定在上方 HUD
- 底部固定 4 个常规技能 + 1 个独立绝招按钮
- PP、伤害、暴击、回血、形态切换继续保留
- 「挑衅」= 无法使用辅助技能
- 「封印」= 无法切换精灵
- nono Lab 与战斗日志改为浮层抽屉，不再挤占战斗画面
- 加入网页全屏按钮，并在竖屏时直接提示旋转手机
- `play.nono.love` 作为正式测试入口

> 项目只借鉴常见的回合制交互结构与机制组合，不使用其他游戏的角色名、技能名或美术资源。当前阶段优先验证战斗底层、横屏排版与手机手感。
